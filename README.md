# Study Assistant RAG

A Study Assistant chatbot built with Retrieval-Augmented Generation (RAG).

## Current Stack

- Python
- Groq API
- Sentence Transformers
- PostgreSQL
- pgvector

## Current Features

- PDF text extraction
- Text cleaning
- Chunking
- Embeddings
- Vector similarity search
- RAG retrieval
- Grounded LLM answers
- Source citations
- Conversation history
